Agentes de impresión

El print-agent corre en la PC de cada sucursal y se conecta él mismo al servidor (WebSocket saliente) para recibir los tickets a imprimir. Ya no hace falta configurar ninguna IP ni puerto desde el navegador — cualquier dispositivo (incluidas tablets) puede mandar a imprimir mientras el agente de esa sucursal esté en línea.

Cómo instalar el agente en una PC nueva
  1. En el servidor, genera el token de esa sucursal (una sola vez por PC): 
    php artisan print-agent:token {almacen_id} --nombre="PC Caja 1"
    Esto imprime un token y confirma el almacenId a usar en el paso siguiente.
  2. Descarga print-agent.exe y cópialo al equipo de la sucursal, por ejemplo en C:\PrintAgent\.
  3. Crea el archivo print-agent.config.json en la misma carpeta (usa print-agent.config.example.json como base) con el nombre exacto de la impresora tal como aparece en Windows y los datos generados en el paso 1: 
    {
  "printerTarget": "PRINTER:Nombre de la impresora",
  "apiBaseUrl": "https://api.comercializadora-guevara.com",
  "reverbHost": "api.comercializadora-guevara.com",
  "reverbPort": 443,
  "reverbScheme": "https",
  "reverbAppKey": "...",
  "almacenId": 1,
  "token": "..."
}
    También se puede usar IP de red "192.168.1.100:9100" o puerto serie "COM3" como printerTarget.
  4. Abre CMD o PowerShell como Administrador y ejecuta: 
    C:\PrintAgent\print-agent.exe install
    Esto crea una tarea programada que arranca el agente automáticamente con Windows, incluso sin iniciar sesión. El agente se conecta él solo al servidor; no hace falta abrir ningún puerto en esa PC ni en el router.
  5. Para probar la impresora directamente desde esa PC (sin pasar por el servidor): 
    C:\PrintAgent\print-agent.exe test
  6. Refresca esta pantalla: la sucursal debería aparecer arriba con el punto en verde unos segundos después de iniciar el agente.
  7. Para desinstalar, abre CMD como Administrador y ejecuta: 
    C:\PrintAgent\print-agent.exe uninstall
