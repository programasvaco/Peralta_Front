Cómo instalar el agente
  1. Descarga print-agent.exe y cópialo al equipo del mostrador, por ejemplo en C:\PrintAgent\.
  2. Crea el archivo print-agent.config.json en la misma carpeta y escribe el nombre exacto de la impresora tal como aparece en Windows (Panel de control → Dispositivos e impresoras): 
    {
  "httpPort": 8183,
  "printerTarget": "PRINTER:Nombre de la impresora"
}
    También puedes usar IP de red "192.168.1.100:9100" o puerto serie "COM3".
  3. Abre CMD o PowerShell como Administrador y ejecuta: 
    C:\PrintAgent\print-agent.exe install
    Esto crea una tarea programada que arranca el agente automáticamente con Windows, incluso sin iniciar sesión.
  4. Pulsa Probar en esta pantalla para verificar que el agente responde. Si todo está bien verás el mensaje "Agente respondió correctamente".
  5. URL según el dispositivo que accede:
    · Mismo equipo del mostrador → http://localhost:8183
    · Tablets / celulares en la misma red → http://<IP-del-mostrador>:8183  (ej. http://192.168.1.10:8183)
  6. Para desinstalar, abre CMD como Administrador y ejecuta: 
    C:\PrintAgent\print-agent.exe uninstall
